Задание 3. Потокобезопасный реестр

SessionRegistry хранит активные сессии в ConcurrentHashMap. computeIfAbsent атомарно получает существующую сессию либо создаёт и публикует новую для данного ключа. Отдельные containsKey и put оставили бы окно гонки. Функция создания короткая, без I/O и побочных эффектов. После удаления следующая операция может создать новую сессию.

Session неизменяема. remove(key, expected) удаляет только запись с равным ожидаемым значением; snapshot возвращает неизменяемую копию. При конкурентных изменениях копия не является атомарным снимком всего реестра, но создание одной сессии атомарно.

Тест запускает 100 обращений из 8 потоков и проверяет, что все получили один и тот же объект сессии. Разные пользователи получают разные сессии.
