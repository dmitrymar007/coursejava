Публичный метод send проверяет адресата, обрезает пробелы и вызывает абстрактный doSend. Email и console варианты реализуют только doSend.

Send можно сделать final, потому что порядок шагов одинаков для всех каналов и менять его подклассам незачем. Final гарантирует, что никто не пропустит проверку адресата, и она написана в одном месте.

Точка расширения это doSend. Он protected abstract: снаружи его вызвать нельзя, а подкласс обязан его реализовать. Правила конкретного канала живут только там, например EmailSender дополнительно проверяет наличие @.
