Задание 3. Полиморфный массив

Массив CourseFormatter[] хранит CompactCourseFormatter, DetailedCourseFormatter и JsonCourseFormatter. CourseReport обходит его и вызывает format для одного курса через интерфейс. Проверки конкретных типов не нужны: реализация выбирается во время выполнения.

Чтобы добавить JSON, достаточно реализовать CourseFormatter и передать новый объект в массив. Код CourseReport и его цикл не меняются, потому что клиент зависит только от контракта format(Course).

Конструктор CourseReport копирует массив через clone, поэтому замена элементов исходного массива не меняет набор форматтеров внутри отчёта.
