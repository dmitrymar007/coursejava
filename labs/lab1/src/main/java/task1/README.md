Компилятор знает только тип переменной, то есть CourseFormatter. Он проверяет, что у этого типа есть метод format(Course), что аргумент подходит и что результат String. Других методов через эту переменную вызвать нельзя: legend() из DetailedCourseFormatter доступен только после instanceof и приведения типа.

Компилятор не знает, какой объект лежит в переменной. Какая реализация format выполнится, определяется во время выполнения по фактическому классу объекта. Строка formatter.format(course) одна и та же, а выполняется то CompactCourseFormatter.format, то DetailedCourseFormatter.format, в зависимости от того, что присвоено переменной.
