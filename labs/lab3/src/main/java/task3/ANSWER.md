Задание 3. Map и индекс

Индекс сделан на HashMap<CourseId, Course>: поиск по ключу за O(1). CourseId это record, поэтому equals и hashCode у ключа правильные.

Повторный ID. Обычный put молча перезаписал бы старый курс. Поэтому используем putIfAbsent: если он вернул не null, такой id уже был, и мы бросаем DuplicateCourseIdException. Индекс при этом не меняется.

Сравнение методов:
get(k) возвращает значение или null. Если значение может быть null, непонятно, нет ключа или значение пустое.
containsKey(k) только проверяет наличие ключа и различает эти два случая.
putIfAbsent(k, v) кладёт значение, только если ключа нет, и возвращает старое. Удобно для обнаружения дубля одним поиском.
computeIfAbsent(k, f) если ключа нет, вызывает функцию и кладёт результат. Функция вызывается лениво, только когда нужна.
