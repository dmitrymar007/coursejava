Задание 5. Безопасное удаление при обходе

Enhanced for работает через Iterator. Список считает свои изменения, а итератор запоминает это число и проверяет его при каждом next. Если удалить элемент через list.remove прямо в цикле, число изменится, и следующий next бросит ConcurrentModificationException.

Исключение появляется не всегда: если удалить предпоследний элемент, hasNext вернёт false, цикл тихо завершится, и последний элемент останется непроверенным. Поэтому на исключение как на защиту полагаться нельзя.

Исправления: удалять через iterator.remove() или использовать list.removeIf(...). removeIf короче и для ArrayList делает один проход.

Копировать всю коллекцию перед обходом не всегда хорошо: это лишние O(n) памяти и времени при каждом вызове, а remove(Object) по копии всё равно ищет элемент и сдвигает хвост. Копия нужна, только когда коллекцию читают параллельно с изменением.
