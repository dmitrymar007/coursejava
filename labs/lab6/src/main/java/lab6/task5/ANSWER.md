Задание 5. Optional как результат

find возвращает Optional<Course> через max по длительности. При равной длительности выбирается максимум по полному компаратору задания 1; правило явно задано и не зависит от порядка входа. describe преобразует найденный курс в строку через map и задаёт fallback «Курсов нет» через orElse.

Optional существует только как результат запроса, в полях Course его нет. Небезопасный get не используется. Fallback — готовая константа, поэтому orElse достаточен; для дорогого вычисления подошёл бы orElseGet. Один поиск занимает O(n) времени и O(1) дополнительной памяти.

Тесты проверяют максимальную длительность, ничью, параллельный поток, единственный курс нулевой длительности и пустой вход.
