Задание 2. flatMap

Каждая строка modules считается одной темой. Нормализация объединяет последовательности Unicode-пробелов, убирает пробелы по краям и приводит к нижнему регистру через Locale.ROOT. Пустые темы отбрасываются. flatMap разворачивает потоки тем отдельных курсов в общий поток без ручного создания вложенного списка.

unique собирает темы в TreeSet. index разворачивает пары topic–course и группирует их в TreeMap. distinct убирает повторы темы внутри курса и повторы одинаковых записей Course во входе. Курсы в индексе сортируются компаратором задания 1. Оба метода возвращают неизменяемые результаты с определённым порядком обхода.

Это два самостоятельных запроса к списку; каждый отдельно использует flatMap. Если нужны оба результата из одноразового источника, их следует собирать совместным collector. Здесь вход — List, повторный запрос разрешён. Тесты проверяют регистр, Unicode-пробелы, пустые темы, дубликаты, обратный индекс и неизменяемость.
