Задание 1. Сортировка и детерминизм

CourseOrder сортирует курсы по возрастанию level, duration и code. Порядок уровней задан enum: BEGINNER, INTERMEDIATE, ADVANCED. Сравнение строк регистрозависимое, длительность измеряется в минутах.

Если все три ключа совпали, дополнительный tie-breaker лексикографически сравнивает списки модулей: сначала элементы, затем длину при совпадении общего префикса. Это делает порядок полным для всех полей Course. Компаратор возвращает 0 только для равных записей, поэтому перестановка входа не меняет результат. Дубликаты сохраняются. Стабильности sorted самой по себе недостаточно: без последнего tie-breaker разные модули могли бы остаться в исходном порядке.

Исходный список не изменяется, результат неизменяемый. Сложность O(n log n), память O(n). Тесты проверяют 40 перестановок, каждый ключ сортировки, дубликаты, пустой вход и защиту результата.
