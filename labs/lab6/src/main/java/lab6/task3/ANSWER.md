Задание 3. reduce с правильной identity

sum складывает длительности как long через reduce с identity 0. combine объединяет неизменяемые value objects Duration с identity Duration.ZERO. plus возвращает новую запись, исходные значения не меняются. Math.addExact явно сообщает о переполнении long, отрицательные длительности запрещены.

Нейтральность: 0 + a = a + 0 = a. Ассоциативность accumulator: (a + b) + c = a + (b + c), пока сумма представима в long. При неотрицательных длительностях переполнение общей суммы нельзя устранить другим порядком группировки. Поэтому частичные результаты можно объединять тем же сложением и получать одинаковый результат последовательно и параллельно.

wrongSum намеренно использует identity 10. Уже пустой поток даёт 10 вместо 0, последовательный результат смещён на 10. В parallel identity добавляется в каждой части, поэтому ошибка зависит от разбиения. Точное число частей не является контрактом Stream API. main показывает оба случая. Тесты проверяют long-сумму, нейтральность, ассоциативность, пустой поток и переполнение.
