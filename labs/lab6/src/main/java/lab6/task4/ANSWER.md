Задание 4. Collectors

byLevel использует groupingBy с TreeMap для порядка уровней. Внутри каждой группы teeing одновременно передаёт курс в toList и summarizingInt. Из списка и статистики сразу создаётся неизменяемый Summary: курсы, count и averageDuration. Поток входных курсов проходит один раз, трёх отдельных полных проходов нет.

После накопления сортируются только списки внутри групп для детерминированного результата. Память O(n), поскольку условие требует сами группы курсов. Время O(n + сумма k log k по группам). Если нужны только количество и среднее, toList и сортировку можно убрать, оставив summarizingInt.

Отсутствующие уровни не включаются в карту; для пустого потока карта пустая. Тесты проверяют группы, среднее 105 для начального уровня, счётчики, порядок, неизменяемость и равенство последовательного и параллельного результата.
