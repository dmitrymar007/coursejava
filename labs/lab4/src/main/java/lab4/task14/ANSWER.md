`Money` — неизменяемый record из BigDecimal и Currency. Scale канонизируется по валюте (RUB/USD 2, JPY 0, KWD 3): поэтому 1 и 1.00 имеют одинаковые equals/hashCode в одной валюте. Разные валюты не равны, add/subtract между ними запрещены. Валюты без установленной точности отклоняются; конвертации по неявному курсу нет.

Конструктор принимает только точную сумму; `of` явно получает режим округления. Add/subtract точны, percentage получает десятичный процент и режим, allocation использует общий детерминированный алгоритм task6. Double в API нет. Отрицательные Money допустимы для разностей/корректировок; в цене и оплате task15 они отдельно запрещены.

Пример: 10% от 3.25 = 0.33 при HALF_UP и 0.32 при HALF_EVEN (последняя сохраняемая цифра чётная). Распределение 1.00 по трём равным весам с DOWN даёт 0.34, 0.33, 0.33; сумма сохраняется, включая распределение отрицательной корректировки.
