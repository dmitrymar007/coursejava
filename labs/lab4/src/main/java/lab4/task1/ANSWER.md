Задание 1. Сравнение строк

Оператор == сравнивает ссылки на объекты, а equals сравнивает содержимое строк. Два одинаковых литерала JAVA-101 дают true в обоих случаях, потому что используют один объект из пула строк.

new String("JAVA-101") создаёт отдельный объект, поэтому == даёт false, а equals даёт true. Выражение "JAVA" + "-101" вычисляется при компиляции и даёт ту же ссылку, что литерал. Если prefix является обычной переменной, выражение prefix + "-101" вычисляется во время выполнения: == даёт false, а equals даёт true при prefix, равном JAVA.

После intern() получаем ссылку на строку из пула, поэтому сравнение с литералом даёт true и через ==, и через equals. Для сравнения текста используем equals независимо от пула. Если допускается null, используем Objects.equals.
