Для значений из `StringIdentityDemo` без аргументов:

| Правая строка относительно литерала `JAVA-101` | `==` | `equals` |
|---|---|---|
| Такой же литерал | true | true |
| `new String("JAVA-101")` | false | true |
| `"JAVA" + "-101"` (константное выражение) | true | true |
| `prefix + "-101"` (runtime) | false | true |
| Результат runtime после `intern()` | true | true |

`==` сравнивает ссылки, `equals` — последовательность символов. Константные строки интернируются; `intern()` возвращает каноническую ссылку. Для текста используем `a.equals(b)`, а при допустимом null — `Objects.equals(a, b)`, независимо от пула.
