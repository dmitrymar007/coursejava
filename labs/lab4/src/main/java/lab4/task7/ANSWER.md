Задание 7. Math и случайные числа

RandomSampleService получает генератор через интерфейс RandomGenerator. Метод seeded использует алгоритм L64X128MixRandom и заданный seed. При одинаковом seed, алгоритме и порядке вызовов получаем одинаковую выборку, что удобно для тестов. Метод production создаёт генератор без фиксированного seed.

Числа выборки находятся в диапазоне от 0 включительно до 100 не включительно. SampleStats хранит значения, минимум, максимум и среднее. Нижняя целая граница вычисляется через Math.floor, верхняя через Math.ceil. Среднее округляется до сотых через Math.round.

Здесь double используется для приближённой учебной статистики. Тесты проверяют повторяемость выборки с seed и свойства результатов. Для production не задаётся заранее ожидаемая последовательность чисел. Такой генератор не предназначен для криптографических задач.
