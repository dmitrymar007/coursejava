Генератор внедряется как `RandomGenerator`. `seeded(seed)` фиксирует алгоритм L64X128MixRandom и seed для повторяемых учебных тестов; `production()` создаёт обычный источник без фиксированного seed. Совпадение seed сравнивается только при том же алгоритме и порядке обращений. Для криптографических задач такой источник не предназначен.

Выборка лежит в `[0, 100)`. `SampleStats` содержит min/max/mean, целые внешние границы вычисляются через `Math.floor/ceil`, среднее округляется до сотых через `Math.round`. Это приближённая статистика double, а не денежный расчёт. Тест проверяет повторяемость и свойства, production-выборка не сравнивается с заранее известными числами.
