`new BigDecimal(0.1)` точно переносит двоичное приближение double: `0.1000000000000000055511151231257827021181583404541015625`.
`BigDecimal.valueOf(0.1)` использует десятичную запись `Double.toString`, здесь `0.1`. Строковый конструктор `new BigDecimal("0.1")` сразу задаёт точную десятичную дробь.

Три курса: `19.90 + 29.95 + 10.15 = 60.00`; также `0.1 + 0.1 + 0.1 = 0.3` точно при строковых входах. Для денежных входов предпочтительны строки/BigDecimal: `valueOf` не исправит погрешность уже выполненных double-вычислений.
