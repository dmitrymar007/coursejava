Задание 5. BigDecimal и double

Число 0.1 нельзя точно представить в double. Поэтому new BigDecimal(0.1) получает двоичное приближение и выводит 0.1000000000000000055511151231257827021181583404541015625.

BigDecimal.valueOf(0.1) использует десятичную запись Double.toString и в этом случае даёт 0.1. Конструктор new BigDecimal("0.1") сразу получает точную десятичную дробь из строки.

Стоимость трёх курсов: 19.90 + 29.95 + 10.15 = 60.00. Если сложить три значения 0.1, созданные из строк, результат будет точно 0.3. Для денежных расчётов используем BigDecimal со строковыми входами. Метод valueOf не исправляет ошибку, если вычисления уже были выполнены через double.
