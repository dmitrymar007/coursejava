Задание 12. Перевод часов

В Europe/Berlin время 31.03.2024 02:30 не существует, потому что часы переводятся вперёд. Обычный atZone автоматически сдвигает его на 03:30. Для занятия выбрано другое правило: LocalDateTimeResolver бросает InvalidLocalTimeException, чтобы организатор указал существующее время.

Время 27.10.2024 02:30 встречается дважды при переводе часов назад. Выбирается первое вхождение со смещением +02, то есть 00:30 UTC. Через час местное время снова будет 02:30, но уже со смещением +01, то есть 01:30 UTC. Метод getValidOffsets показывает допустимые смещения, а ofStrict создаёт время с выбранным смещением.

plusHours(1) добавляет ровно 3600 секунд. plusDays(1) добавляет календарный день с учётом правил зоны: от 30.03.2024 12:00 до 31.03.2024 12:00 проходит 23 часа. При попадании в несуществующее время plusDays использует обычный сдвиг, поэтому для расписания каждую дату отдельно проверяем через LocalDateTimeResolver.
