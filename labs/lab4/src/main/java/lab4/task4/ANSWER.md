Задание 4. Autoboxing и null

При преобразовании Integer в int вызывается intValue(). Если Integer равен null, возникает NullPointerException. Метод unsafeUnbox и пример в main воспроизводят эту ошибку.

В main сравниваются объекты Integer со значениями 127, 128 и 1000. Для 127 упаковка использует гарантированный кэш, поэтому ссылки совпадают. Для 128 и 1000 результат == может зависеть от реализации и настроек кэша. Использовать такое сравнение для проверки числовых значений нельзя.

В sameValue задан явный контракт: оба аргумента обязательны. Objects.requireNonNull проверяет их и указывает имя отсутствующего аргумента, после чего сравниваются значения int. Если null допустим по смыслу задачи, можно использовать Objects.equals. Тесты не зависят от размера кэша Integer.
