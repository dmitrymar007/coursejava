Unboxing null (`Integer` → `int`) вызывает NPE: фактически требуется `intValue()` у отсутствующего объекта. `unsafeUnbox` и демонстрация воспроизводят ошибку.

В `main` сравниваются 127, 128 и 1000. Для 127 autoboxing использует гарантированный кэш, поэтому ссылки совпадут. Для 128 и 1000 результат `==` зависит от реализации/настроек расширенного кэша; фиксировать false как контракт нельзя.

Исправленный контракт `sameValue`: оба аргумента обязательны, null отклоняется с именем аргумента, затем сравниваются примитивные значения. Если по смыслу null допустим, альтернативой был бы `Objects.equals`. Тесты не предполагают конкретной верхней границы кэша.
