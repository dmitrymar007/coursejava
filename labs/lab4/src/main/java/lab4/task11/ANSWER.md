Момент вебинара хранится как `Instant`. Для `2024-03-31T08:00Z` отображение: Berlin 10:00 (+02), Novosibirsk 15:00 (+07), New York 04:00 (−04). Во всех трёх случаях `toInstant()` возвращает один момент.

Пользовательский `ZoneId` передаётся явно. Неявный `systemDefault()` сделал бы локальное представление зависимым от настроек сервера. Тест временно меняет серверную зону и подтверждает одинаковый результат явного преобразования, затем восстанавливает настройку.
