Контракт кода: одна или несколько заглавных ASCII-букв, обычный дефис, ровно три ASCII-цифры. Именованные группы `prefix` и `number` извлекаются через `Matcher`; `matches()`, в отличие от `find()`, требует совпадения всей строки. Числовую часть сохраняем строкой, чтобы не потерять ведущие нули.

| Значение | Результат |
|---|---|
| `JAVA-101` | prefix=JAVA, number=101 |
| `SQL-007` | prefix=SQL, number=007 |
| `java-101`, `ЯВА-101` | неверный алфавит/регистр |
| `JAVA-١٠١`, `JAVA-１０１` | Unicode-цифры запрещены |
| ` JAVA-101`, `JAVA-101 `, строка с переводом строки в конце | пробелы запрещены |
| `JAVA-10`, `JAVA-1001` | неверное число цифр |
| `xJAVA-101x`, `JAVA–101` | частичное совпадение / другой дефис |
| null, пустая строка | отклоняются |
