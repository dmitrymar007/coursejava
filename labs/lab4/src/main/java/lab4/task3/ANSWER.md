Задание 3. Регулярное выражение с группами

Код курса состоит из одной или нескольких заглавных латинских букв, обычного дефиса и ровно трёх ASCII-цифр. Именованные группы prefix и number позволяют получить буквенную и числовую части. Метод matches проверяет всю строку, поэтому частичное совпадение не принимается.

JAVA-101 подходит: prefix равен JAVA, number равен 101. SQL-007 тоже подходит: prefix равен SQL, number равен 007. Числовая часть хранится строкой, чтобы сохранить ведущие нули.

java-101 не подходит из-за регистра, ЯВА-101 из-за кириллицы. Коды с арабскими или полноширинными Unicode-цифрами тоже отклоняются. Пробелы по краям и перевод строки в конце запрещены.

JAVA-10 и JAVA-1001 не подходят из-за количества цифр. xJAVA-101x отклоняется, потому что совпадение должно занимать всю строку. Код с длинным тире вместо обычного дефиса, пустая строка и null также отклоняются.
