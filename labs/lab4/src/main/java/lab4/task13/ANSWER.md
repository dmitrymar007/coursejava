Pipeline ключа: `strip` → схлопывание Unicode-пробелов до обычного пробела → удаление краевых пробелов → `toLowerCase(Locale.ROOT)`. Дополнительный strip после схлопывания убирает NBSP по краям, который первый `strip` не удаляет. Фиксированная locale исключает зависимость, например, от турецких настроек системы.

`displayValue` сохраняется без изменений для показа пользователю. `searchKey` вычисляется отдельно: `"  Java\t BASICS  "` и `"java\u00a0basics"` дают `java basics`. Значит, поисковый ключ не является уникальным id: индекс должен хранить несколько совпадений или явно обрабатывать конфликт.

Здесь case folding реализован как приведение к нижнему регистру по фиксированной locale согласно условию; полное Unicode folding (например, приравнивание ß и ss), удаление диакритики и Unicode-нормализация не добавляются.
