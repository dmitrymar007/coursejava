Задание 13. Нормализованный поиск

CourseTitle отдельно хранит исходное название displayValue и вычисляет поисковый ключ searchKey. Исходная строка остаётся без изменений для отображения пользователю.

При получении ключа сначала вызывается strip, затем последовательности пробельных символов заменяются одним обычным пробелом. После этого снова убираются пробелы по краям, а буквы переводятся в нижний регистр через Locale.ROOT. Второй strip нужен в том числе для неразрывных пробелов, которые первый strip не удаляет, но замена превращает в обычные пробелы.

Название Java BASICS с лишними пробелами и табуляцией даёт тот же ключ java basics, что и название java basics с неразрывным пробелом. Исходные строки разные, поэтому поисковый ключ нельзя считать уникальным идентификатором.

Locale.ROOT делает результат независимым от языка системы, например турецкого. Здесь меняется только регистр и пробелы: приравнивание немецкой буквы ß к ss и удаление диакритики не выполняются. Пустое после нормализации название запрещено.
