Задание 2. Сборка строки

ReportBuilder собирает отчёт из 10 000 строк двумя способами: через + в цикле и через StringBuilder. Результаты одинаковые, каждая строка содержит Course и номер курса.

String неизменяем: при конкатенации старая строка не дополняется, а результат присваивается переменной заново. В цикле приходится снова копировать уже собранный текст, поэтому суммарный объём копирования растёт квадратично. StringBuilder накапливает текст в изменяемом буфере, поэтому сборка растёт линейно по длине результата.
