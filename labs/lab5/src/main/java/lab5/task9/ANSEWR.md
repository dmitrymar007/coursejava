Задание 9. Версионируемый формат

Заголовок: magic 0x43415439 (int), schema version (int), CRC32 (long); далее payload с количеством записей (int). V1 содержит id (int) и title (writeUTF), V2 добавляет category (writeUTF). CRC32 считается по версии (один байт для поддерживаемых 1 и 2) и всем байтам payload. Неизвестная версия отклоняется сразу.

Сначала проверяется checksum, затем создаются объекты; результат публикуется только после проверки всего payload. Миграция V1 → V2 сохраняет id/title и добавляет категорию «Общее». writeV1 создаёт старый формат для демонстрации; write всегда сохраняет V2. CRC32 обнаруживает случайное повреждение, криптографической защитой не является. Payload здесь хранится в памяти; потоковая обработка большого файла показана в задании 8.

Тест проверяет V2, миграцию с повторным сохранением, пустой каталог, будущую версию, повреждение заголовка/checksum/payload, подмену известной версии и каждую длину обрезки образца.
