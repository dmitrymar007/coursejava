Задание 7. Частично повреждённый импорт

Контракт AtomicImporter — all-or-nothing: sealed Result содержит либо Success с полным неизменяемым списком курсов, либо Failure только с неизменяемым списком ошибок. Каждая ошибка содержит номер строки с 1 и причину. При любой неверной строке накопленные курсы наружу не передаются. Пустые строки тоже считаются ошибками; пустой файл даёт Success с пустым списком.

Файловые ошибки передаются как IOException, частичный результат при них тоже не публикуется. Тест смешивает верные и неверные строки, проверяет номера ошибок, успешный импорт и неизменяемость результатов.
