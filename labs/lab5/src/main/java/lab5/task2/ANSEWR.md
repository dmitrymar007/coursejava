Задание 2. Reader/Writer

BufferedText копирует текст построчно через BufferedReader/BufferedWriter и закрывает их в try-with-resources. Счётчик chars суммирует String.length(): единицы UTF-16 без разделителей строк. Например, Я — один char, 😀 — два. readLine убирает разделитель, newLine записывает системный разделитель, в том числе после последней строки.

Граница bytes → chars находится в декодере UTF-8 при создании reader: файловые байты преобразуются в символы. Writer выполняет обратное кодирование. Число байтов UTF-8, char и видимых символов может различаться. Тест проверяет кириллицу, emoji, пустые строки и пустой файл.
