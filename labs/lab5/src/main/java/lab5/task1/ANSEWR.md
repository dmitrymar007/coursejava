Задание 1. Files.readString/writeString

TextCatalog сохраняет и читает каталог в UTF-8. Пустой файл означает пустой каталог. Ошибки не скрываются: отсутствие файла передаётся вызывающему коду как NoSuchFileException, каталог вместо файла — как IOException. Успех возможен только после завершения операции; main тоже передаёт IOException наружу.

Тест проверяет точные байты UTF-8, чтение после записи, пустой каталог и обе файловые ошибки.
