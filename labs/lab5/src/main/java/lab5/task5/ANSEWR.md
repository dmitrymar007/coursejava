Задание 5. Бинарный формат

BinaryCatalog записывает DataOutputStream: magic 0x43415435 (int), version=1 (int), количество (int), затем для каждого курса id (int) и title (writeUTF). Чтение DataInputStream идёт в том же порядке. writeUTF использует modified UTF-8 с длиной до 65535 байт; это ограничение выбранного формата.

Читатель отклоняет неверный magic, неизвестную версию, отрицательное количество, неверные записи, обрезанный файл и лишний хвост. Список возвращается только после полной проверки. Тест проверяет обратное чтение, пустой каталог, повреждённый заголовок и каждую возможную длину обрезки образца.
