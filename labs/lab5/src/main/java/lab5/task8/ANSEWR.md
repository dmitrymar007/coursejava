Задание 8. Потоковый импорт большого файла

StreamingImporter читает BufferedReader по одной строке, сразу передаёт верные курсы в Consumer и не хранит каталог. Summary содержит число прочитанных строк, принятых курсов, всех ошибок, ограниченную выборку ошибок и признак отмены. Достижение cancelAfterErrors завершает импорт сразу после ошибочной строки; errorLimit ограничивает только число сохранённых сообщений. Счётчики имеют тип long.

Контракт потоковый: уже переданные Consumer курсы сохраняются при отмене, отката нет. Consumer должен сам обрабатывать данные без накопления. Его исключения не считаются ошибками входных строк. Память импортёра зависит от длины одной строки и лимита сообщений, а не размера файла.

Тесты проверяют счётчики, границу отмены, лимит сообщений и ошибку Consumer. Отдельная JVM с heap 16 МиБ полностью читает файл из 700 000 строк размером больше heap.
