Задание 6. Временный файл и move

AtomicCatalog создаёт временный файл рядом с целевым, записывает UTF-8, выполняет flush и close, затем Files.move с ATOMIC_MOVE и REPLACE_EXISTING. При AtomicMoveNotSupportedException повторяет move только с REPLACE_EXISTING. Такой fallback заменяет файл без гарантии атомарности; остальные ошибки передаются вызывающему коду. finally удаляет оставшийся временный файл.

flush/close передают буферы файловой системе, но не гарантируют сохранность при отключении питания. Тест проверяет обычную запись, принудительный fallback, готовое содержимое до move и сохранение старого файла с удалением временного при ошибке move до замены.
