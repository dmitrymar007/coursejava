# Задание 7. Ошибка как значение или исключение

- findCourse - Optional. Курс может не найтись, это обычный ожидаемый исход, а не ошибка.
- parseCourse - Checked exception. Вход приходит снаружи и может быть некорректным. Вызывающий код может пропустить запись или сообщить о ней.
- enroll - Checked exception. Отказ (нет мест, повторная заявка) ожидаем, и вызывающий код обязан его обработать.
- calculatePrice - Unchecked exception. Отрицательные часы или цена - ошибка вызывающего кода, а не штатный результат.

Реализованы два контрастных случая: findCourse (значение) и calculatePrice (исключение).

Граница ожидаемого результата:
- Отсутствие курса - это Optional.empty(), исключения нет.
- Некорректный аргумент - это исключение, а не Optional.empty().
- `null` вместо id - ошибка программиста, `findCourse` выбрасывает исключение, а не возвращает `empty()`.
