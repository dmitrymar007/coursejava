Задание 9. Граничные значения

Контракт длительности курса: целое число от 1 до 300 включительно. Тесты проверяют четыре значения: 0 и 301 дают IllegalArgumentException, 1 и 300 принимаются и сохраняются в durationHours.

Для отказов проверяются тип исключения и сообщение с недопустимым значением. Для допустимых границ — сохранённая длительность.

Обычный пример, например 32 часа, проходит и при ошибочной проверке durationHours < 300. Только проверка самой границы обнаружит, что допустимое значение 300 ошибочно отвергается. Значения сразу за границами проверяют, что диапазон не расширен на единицу.
