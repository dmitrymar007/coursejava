Задание 10. Параметризованный тест

CourseCode.of обрезает пробелы по краям, переводит буквы в верхний регистр через Locale.ROOT и проверяет формат: 2–4 латинские буквы, дефис, 3 ASCII-цифры. Нормализованное значение неизменяемо, equals и hashCode считают его одинаково.

@ParameterizedTest с @CsvSource задаёт пары «вход — ожидаемый код». Один тестовый метод отдельно запускается для каждой пары: проверяются регистр, пробелы и ведущие нули. Имя запуска показывает исходную строку и ожидаемый результат.

Недопустимые строки передаются через @NullAndEmptySource и @ValueSource. Для каждой ожидается IllegalArgumentException; имя запуска показывает неверный вход. Отдельный тест подтверждает равенство кодов после нормализации.
