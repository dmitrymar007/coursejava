# Задание 2.

- неверный аргумент метода - Unchecked. Это ошибка вызывающего кода, нарушен контракт метода. Обработать её на месте нельзя, нужно исправить вызов.
- отсутствующий файл - Checked. Ситуация ожидаема и не зависит от корректности кода. Вызывающий код может взять другой путь или сообщить пользователю, поэтому компилятор требует её обработать.
- нарушение состояния - Unchecked. Метод вызван в неподходящий момент, это ошибка логики программы. Исправлять нужно код, а не ловить исключение.
- сетевой отказ - Checked. Сеть ненадёжна независимо от кода: таймаут, обрыв, недоступный сервер. Отказ можно обработать повтором или запасным вариантом, поэтому он указывается в сигнатуре.
- ошибка конфигурации - Unchecked. Это ошибка развёртывания, локально её не исправить. Приложение должно сразу упасть при старте с понятным сообщением.
- недостаток памяти - Невозможность восстановления. Это сбой среды выполнения (`OutOfMemoryError`), после него состояние программы непредсказуемо. Ловить его бессмысленно, можно только залогировать и завершить работу.
