Задание 15. Планировщик prerequisites

Граф хранится как Map<V, Set<V>>: для каждого курса множество его prerequisites. Результат это Plan: либо порядок изучения, либо цикл.

Алгоритм: поиск в глубину. Вершина на текущем пути помечается как посещаемая, после обработки всех её prerequisites она попадает в порядок, поэтому каждый курс стоит после своих prerequisites. Если из вершины мы пришли в вершину, которая ещё на текущем пути, найден цикл, и его путь вырезается из пути обхода, например Java -> Spring -> Streams -> Collections -> OOP -> Java.

Коллекции: LinkedHashMap и LinkedHashSet, потому что они обходятся в порядке добавления. Поэтому при одинаковом вводе результат всегда одинаков. HashMap и HashSet дали бы порядок, зависящий от хешей. Состояние обхода лежит в HashMap, путь в ArrayList.

Сложность: O(V + E) по времени и памяти. Добавление вершины и ребра O(1). Поиск рекурсивный, поэтому на очень длинных цепочках возможен StackOverflowError, для учебного графа это неважно.

Отсутствующая вершина: addDependency с неизвестной вершиной бросает NoSuchElementException, чтобы опечатка не создавала новый курс молча.
