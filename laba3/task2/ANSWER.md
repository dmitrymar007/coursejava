Задание 2. Set и уникальность

Берём LinkedHashSet: он убирает дубликаты и хранит порядок первого появления. HashSet порядок не гарантирует, TreeSet сортирует, а не хранит порядок появления.

Как equals и hashCode влияют на set: хеш-коллекция сначала сравнивает hashCode, потом equals. Если у класса нет своих equals/hashCode, объекты равны только по ссылке, и два одинаковых по смыслу кода не считаются дубликатами. Если переопределён только один из методов, равные объекты могут попасть в разные корзины, и дубликат тоже не найдётся. Правило: равные по equals объекты обязаны иметь одинаковый hashCode.

В CourseCode значение приводится к верхнему регистру без пробелов, а equals и hashCode считаются по этому неизменяемому полю.
